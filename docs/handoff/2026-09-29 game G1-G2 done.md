## Rules and gotchas learned

- **Nothing about MiniBrain in the Obsidian vault** (no journal, Planner, Handoff, Topics, Marketing, Logbook). The
  SessionEnd hook `~/.claude/hooks/obsidian-journal/session-end.mjs` excludes `c:/java/minibrain`. Handoffs go here.
- Tests only via the `test-runner` agent. The in-memory test DB is **shared between test classes** (same context):
  use unique key prefixes and before/after deltas; for a known game state use `@MockitoBean GameQuery` (own context).
- Live checks that write: restart with `MINIBRAIN_DB_URL=jdbc:sqlite:<scratchpad>/demo.db` (copy of the real DB),
  seed via `/api/imports/preview` + `/apply`, and **restart on the real DB afterwards** (remove the env var). Back up
  the real DB into `backups/` before any new migration runs on it.
- Bash tool: heredocs with apostrophes or `\\` break. Write edit scripts / long text with the Write tool into the
  scratchpad, then run `python script.py`.
- Vite dev server can keep a stale module after many rapid edits (white screen, "does not provide an export named");
  restart via `dev.ps1`.
- React Flow with controlled nodes: drag positions arrive via `onNodesChange`; keep `measured` sizes on rebuilt nodes
  or the drag jumps (warning #015). Playwright `dragTo` is one mouse step: use `page.mouse` with `steps`.
- SQLite cannot alter a CHECK constraint: rebuild the table (see V10).
